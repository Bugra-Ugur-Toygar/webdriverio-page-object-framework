# WebdriverIO page object framework

Automates the Practice Software Testing Toolshop scenarios.

## Prerequisites

Node.js 22.19.0 or newer.

## Install

npm install

## Run

npm test

## Layers

- `core/` is generic framework code that is not specific to this shop.
- `business/` is the Toolshop pages, header, shared flows, and test data.
- `tests/` is the WebdriverIO configuration and the scenario specs.
